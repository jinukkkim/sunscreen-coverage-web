# 기상청 지점 자료

`kma-locations.json`은 공공데이터포털의 기상청 생활기상지수 4.0 공식 첨부파일에 포함된 `dfs-zone-tree_excel_20260930.xlsx`에서 가져왔습니다. 2026-09-30 기준 3,839개 국내 지점의 행정구역 코드, 명칭, 격자, 좌표입니다. `scripts/import-kma-locations.py`로 필요한 열만 JSON으로 변환했습니다.

출처: 기상청, [생활기상지수 조회서비스(4.0)](https://www.data.go.kr/data/15085288/openapi.do). 첨부파일: `생활기상지수 조회서비스(4.0)_오픈API활용가이드★★.zip` (FILE_000000007751864).

위치에서 가장 가까운 등록 지점을 사용합니다. 법정·행정 경계 안에 속하는 지점을 판별하는 방식은 아니며, 화면에 인근 지점과 거리를 명시합니다. 50km 이내 지점이 없으면 지원 범위 밖으로 처리합니다. 전체 표는 서버에만 포함하며 브라우저로 배포하지 않습니다.
