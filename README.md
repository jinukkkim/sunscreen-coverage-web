# SunGuard

2026 서울시립대학교 해커톤 팀이 진행하는 선크림 도포 인식 웹 프로젝트입니다.

선크림을 바를 때 빠뜨린 부위를 알아차리고 보완하도록 돕는 것을 목표로 합니다. 현재는 기획·기술 검증 단계이며, 기본 카메라를 이용한 실제 도포 인식 정확도는 아직 검증되지 않았습니다.

팀이 함께 작성·검토하는 프로젝트이며, MIT 라이선스로 공개합니다.

## 개발 시작

Node.js 22.12 이상을 사용합니다.

```sh
npm ci
npm run dev
```

터미널에 표시되는 localhost 주소를 브라우저에서 여세요. 휴대폰 카메라는 HTTPS 주소가 필요합니다. 배포 방식과 서버 구성은 추후 결정합니다.

```sh
npm test
npm run build
npm run preview
```

`preview`는 로컬 빌드 확인용이며 운영 서버가 아닙니다.

## 스켈레톤 범위

- React/Vite 앱 진입점, 반응형 기본 화면, 카메라 켜기·끄기·권한 오류 처리.
- 도포 결과·자외선·성분 분석·덧바름 알림은 미연결 상태로 표시합니다.
- 데모 데이터, 터치 시연, UV 슬라이더, 샘플 성분, 임의 도포율 및 보호 시간 계산을 포함하지 않습니다.
- 카메라 영상은 브라우저 미리보기에만 사용합니다. 캡처·저장·외부 전송·모델 실행은 하지 않습니다. API 키나 환경 변수 없이 실행됩니다.

## 코드 구조와 다음 연결 지점

| 경로 | 역할 |
| --- | --- |
| `src/App.jsx` | 기능별 화면과 빈 결과 영역 |
| `src/components/Camera.jsx` | 사용자 동작에 따른 카메라 상태와 미리보기 |
| `src/lib/camera.js` | 스트림 수명 관리 및 요청 취소 |
| `tests/camera.test.js` | 종료·취소·재요청·재생 실패 시 자원 해제 검증 |

실제 도포 인식은 검증된 모델·결과 계약을 정한 뒤 카메라 입력과 연결합니다. 손 이동만으로 도포 완료를 표시하지 않습니다. 외부 분석을 도입하면 이미지 전송 대상·저장 정책·동의 흐름을 먼저 문서화해야 합니다.

카메라 자동 테스트는 모의 스트림으로 수명 관리를 검사합니다. 실제 기기에서 권한 허용·거부, 영상 표시, 끄기 후 카메라 해제는 별도로 확인해야 합니다.

공유 조사 자료는 [문서 목차](docs/README.md)에서 확인할 수 있습니다.
