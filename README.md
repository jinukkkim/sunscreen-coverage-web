# SunGuard 얼굴 기반 사용량 실험 가이드

카메라 또는 사진에서 얼굴 랜드마크를 찾고, 홍채 지름 가정으로 환산한 **부분 얼굴 영역**의 면적과 손가락 줄 길이 참고값을 보여주는 정적 웹 앱입니다. 도포 여부·균일함·SPF/UVA 보호를 측정하지 않습니다.

## 개발 시작

Node.js 22.12 이상을 사용합니다.

```sh
npm ci
npm run dev
```

Vite가 출력하는 localhost 주소를 여세요. 카메라는 HTTPS 또는 localhost에서만 사용할 수 있습니다. 분석 모델은 첫 실행 때 사이트에서 내려받아 기기 안에서 실행합니다.

```sh
npm test
npm run build
npm run preview
```

정적 호스팅에는 `npm run build`의 `dist/` 내용을 게시해야 합니다. 빌드 전처리가 MediaPipe WebAssembly 런타임을 `public/vendor/wasm/`에 준비하며 이 생성 파일은 Git에 올리지 않습니다. `public/models/face_landmarker.task`는 공식 모델 고정본으로 저장소에 포함됩니다.

## 현재 기능

- MediaPipe Face Landmarker를 이용한 브라우저 카메라 캡처 또는 JPG/PNG/WebP/AVIF 사진 분석.
- 양쪽 홍채, 눈 사이 거리, 얼굴 윤곽을 확인하고, 한 얼굴만 있는 입력을 받습니다.
- 11.7mm 평균 홍채 지름 가정으로 얼굴 크기를 환산합니다. 얼굴 메시 삼각형에서 눈과 입술을 뺀 검출 영역의 면적을 합산하고, 2mg/cm²를 곱한 계산값을 표시합니다.
- 같은 영역의 결과를 고정된 참고 조건(5mm 줄 굵기, 25mm당 0.5g)으로 손가락 줄 길이와 사용자가 조절한 검지 마디 길이로 바꿔 보여줍니다.
- 입력 이미지/영상은 브라우저 메모리에서만 처리합니다. 앱 코드가 사진이나 영상을 서버로 보내거나 저장하지 않습니다. 실행 모델과 WASM 파일은 사이트에서 가져옵니다.

## 해석할 때 주의할 점

- 표시하는 면적은 실제 얼굴 전체 피부 면적이 아닙니다. 이마 위쪽 일부·옆면·귀·목은 빠질 수 있습니다. 얼굴 깊이는 모델의 상대값을 사용하므로 실제 피부 곡면을 측정하지 않습니다.
- 11.7mm 홍채 지름은 개인별 실측값이 아닌 기준 가정입니다. 화면의 민감도 범위는 홍채 가정만 바꾼 계산이며 신뢰구간이나 전체 오차 범위가 아닙니다.
- 2mg/cm²는 시험 면적당 계산 기준을 적용한 것입니다. 이 값을 해당 얼굴 전체의 충분한 사용량 또는 제품 사용 지시로 해석하면 안 됩니다. 제품 표기와 사용 안내를 우선하세요.
- 제품은 사용자가 지정한 조선미녀 맑은쌀 선크림 아쿠아프레쉬 10mL 비매품입니다. 이 용기의 입구 크기와 실제 토출 질량은 측정하지 않았습니다. 손가락 환산값 역시 제품 실측값이 아닌 시연용 참고 조건입니다.
- 정면·밝은 조명·얼굴 전체와 양쪽 눈이 보이는 사진을 사용하세요. 랜드마크가 잡혀도 면적 추정이 정확하다는 보장은 없습니다.

## 구조

| 경로 | 역할 |
| --- | --- |
| `index.html`, `src/styles.css` | 한국어 반응형 화면 및 Cloudflare 참고 디자인 |
| `src/main.js` | 카메라·사진 입력, 진행 상태, 결과 렌더링 |
| `src/lib/vision.js` | MediaPipe 브라우저 모델 로딩 |
| `src/lib/measurement.js`, `topology.js` | 얼굴 메시 면적 및 크기 환산 |
| `src/lib/dose.js` | 2mg/cm² 계산과 참고 손가락 환산 |
| `src/lib/camera.js`, `operation.js` | 스트림 종료와 비동기 분석 취소 |
| `tests/` | 기하 변환·면적 가정·취소 및 카메라 자원 처리 테스트 |
| `docs/sunguard/` | 프로젝트 조사·기획 및 근거 문서 |
| `THIRD_PARTY_NOTICES.md` | MediaPipe 런타임과 모델 출처·라이선스 |

프로젝트의 제품 목표인 실제 선크림 도포 인식은 아직 연결되거나 검증되지 않았습니다. 얼굴 크기와 사용량의 관계 또한 이 프로토타입에서 실험 추정으로 표시합니다.
