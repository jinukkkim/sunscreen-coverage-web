# 얼굴 기반 선크림 양 가이드

사용자가 승인한 통합 흐름을 HTML/CSS/JavaScript로 구현한다. 전용 clone의 feat/face-dose-guide에서 작업하며 원격 push/PR 생성은 하지 않는다.

## 범위와 선택
- 기존 React skeleton을 프레임워크 없는 Vite 정적 앱으로 전환한다. 사용자 지정 기술을 우선한다.
- Cloudflare 참고 자료의 white/orange blueprint, hairline grid, pill buttons와 한국어 UI를 적용한다.
- 제품은 사용자 지정 조선미녀 맑은쌀 선크림 아쿠아프레쉬 10mL 비매품이다. 공식 제품명 외 소용량 용기 제원은 검증되지 않았다.
- 실제 카메라 또는 사용자 사진 업로드로 MediaPipe Face Landmarker를 실행한다. 임의 결과/내장 참가자 사진은 제공하지 않는다.
- 평균 홍채 11.7mm로 크기를 환산하고, relative-z 삼각형 mesh의 눈/입술 제외 영역 면적을 합산한다. 그 영역에 2mg/cm²를 곱한다. 얼굴 전체 면적 또는 처방/차단력으로 표시하지 않는다.
- 제품의 검증된 토출 데이터가 없으므로 손가락 안내는 표준 5mm 줄, 25mm당 0.5g이라는 명시적인 시연용 가정이다. 실제 BOJ mini의 측정값이 아니다. 보정/실측 필요 상태를 항상 함께 표시한다.
- 손가락 한마디 길이를 선택적으로 변경해 비율을 확인할 수 있다. 화면상의 그림은 실제 자가 아니다.
- 얼굴 영상/사진은 메모리에서만 처리하고 외부 전송/저장하지 않는다. 모델과 WASM은 same-origin으로 제공한다.

## 대안
MICA는 별도 모델/실행환경이 필요해 이번 범위에서 제외했다. 검증되지 않은 전체 얼굴 보정계수 대신 앞서 실행한 부분 mesh 계산을 그대로 사용한다. 라이브 손 길이 인식 대신 이번 요청의 첫 버전은 손가락 비례 그림을 사용한다.

## 상태와 오류
카메라 시작/취소/정지, 사진 선택, 모델 로딩/실패/재시도, 0명/다수 얼굴/작은 홍채/비정면 재촬영, 분석 중 취소, 결과 초기화가 필요하다. 소스 변경과 새 분석 시작 시 이전 결과를 무효화한다. 숨김/종료 시 스트림을 해제한다.

## 검증
실제 면적/단위 변환의 synthetic geometry 테스트, 입력/품질 거절 테스트, 제품 미검증과 손길이 환산 테스트, 기존 camera lifecycle tests. 실제 제공 사진은 QA에서만 사용하며 repository에는 커밋하지 않는다. 데스크톱/모바일 UI 및 모델 실행/오류를 브라우저로 확인한다.
