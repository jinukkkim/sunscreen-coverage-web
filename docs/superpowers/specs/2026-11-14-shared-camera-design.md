# 사용량과 도포 동작의 단일 카메라

사용자가 요청한 대로 ‘바르기 전에, 얼마나?’와 도포 인식을 하나의 작업 영역으로 합친다. 오늘의 선크림 제품 박스와 고정 제품 전용 설명을 제거한다. 기존 흰색·주황색 디자인과 내 선크림 등록은 유지한다.

## 선택
카메라를 두 번 열거나 영상 요소만 옮기지 않고 하나의 스트림·얼굴 스캔 결과를 재사용한다. 기존 VIDEO 얼굴 모델이 안정적인 정면 얼굴을 확인하면 홍채 기반 사용량을 추정한다. 사용자는 요약을 보고 ‘부위 확인 후 시작’을 눌러 같은 영상에서 동작 관찰을 시작한다. 홍채 품질이 부족해도 사용량 추정 실패와 동작 관찰 가능 여부는 구분한다.

## 화면과 수명
왼쪽에 하나의 영상·사진 입력, 오른쪽에 사용량 요약과 부위별 진행률, 아래에 상세 면적·손가락 안내를 둔다. 별도의 도포 카메라 영역을 없앤다. 사진 업로드는 같은 미리보기에서 사용량만 분석하고 실제 동작/기록을 만들지 않는다. 카메라 중단·초기화·새 도포와 재시도는 한 컨트롤러에서 관리한다. 완료 시 마지막 프레임과 결과를 유지하고 새 도포는 기존 스트림으로 시작한다. 숨김 중 움직임 적립을 멈추고 복귀 시 기존 진행률과 재확인 정책을 보존한다.

## 보존과 검증
5구역 전체 완료 기록·중복 방지·UV 알림·종료 시각·개인정보 정책을 보존한다. 단일 video와 단일 getUserMedia 호출, 스캔→계산→동작 전환, 사진 오류/결과/초기화, 늦은 카메라 권한과 모델 응답 해제, 기존 완료·회복·알림 테스트, 모바일·빌드·Astryx doctor를 검증한다.
