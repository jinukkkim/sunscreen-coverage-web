# SUNFIT 홈과 얼굴 사용량 가이드 통합

> 후속 단일 카메라 요청은 `2026-11-14-shared-camera` 설계·계획으로 대체. 아래 내용은 첫 홈 통합 단계의 기록.
## 목적
오른쪽 위 버튼을 통해 별도 페이지로 이동하던 얼굴 크기·사용량 가이드를 홈으로 통합한다. 사용자가 지정한 기존 가이드의 흰색·주황색 디자인을 홈 전체의 기준으로 사용한다.

## 접근
기존 React 홈에 얼굴 가이드를 React 구성요소로 옮긴다. 별도 페이지를 iframe으로 삽입하는 방식은 중복 화면 구조와 카메라 생명주기 관리가 남으므로 선택하지 않는다. 정적 가이드에 기존 앱을 따로 삽입하는 방식도 상태와 테마가 분리되므로 선택하지 않는다.

## 화면
상단 브랜드와 페이지 내 이동 → 기존 가이드의 주황색 히어로 → 얼굴 촬영·사진 선택과 사용량 결과 → 도포 동작 관찰 → 재도포 일정·기록·알림 → 내 선크림 등록 → 계산 근거·개인정보 안내 순서다. 모바일에서는 한 열로 배치한다. 가이드 결과에서 동작 관찰로 이동하는 버튼은 같은 홈 안의 해당 영역으로 이동한다. 촬영과 관찰은 각각 명시적으로 시작하며 한쪽을 시작하면 다른 쪽 카메라를 정지한다.

## 구현 기준
기존 React/Vite/Astryx 구조와 공용 얼굴 모델·계산 함수를 재사용한다. 가이드의 주황색, 흰 배경, 얇은 구분선, 둥근 버튼, 얼굴 도식을 Astryx 구성요소와 테마 토큰으로 옮긴다. 기존 `/face-dose.html` 주소는 홈의 가이드 영역으로 연결하여 이전 링크도 사용할 수 있게 한다.

## 보존할 동작
사진 입력 검증, 취소·재시도·초기화, 숨김·종료 시 카메라 해제를 유지한다. 면적과 사용량은 표시 영역의 실험 추정이며 실제 도포량·보호력으로 표현하지 않는다. 얼굴 사진·영상은 브라우저 메모리에서만 처리한다. 동작 관찰 5구역 완료 시 한 번만 기록하며 기존 UV 정책, 알림 종료 시각, 제품 등록과 저장 기록을 보존한다. 사용량 추정만으로 도포 완료를 기록하지 않는다.

## 검증
기존 단위 테스트와 홈 브라우저 테스트를 실행한다. 별도 페이지 이동 테스트를 홈 내 가이드·결과·관찰 이동 테스트로 바꾸고, 입력 오류와 카메라 전환 시 해제를 확인한다. 모바일 가로 넘침과 데스크톱 화면을 확인하며 프로덕션 빌드와 Astryx doctor를 통과시킨다.
