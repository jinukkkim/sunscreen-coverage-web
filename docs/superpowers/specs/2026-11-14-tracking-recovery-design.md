# 일시적 인식 손실 후 진행률 복구

## 목적
작은 자세 변화나 순간적인 얼굴 누락으로 이미 관찰한 부위별 퍼센트가 초기화되지 않게 한다. 감지 실패 중에는 동작을 적립하거나 완료를 기록하지 않는다.

## 현재 원인
`vision-session.js`의 `scanAgain()`이 `blank()`를 호출하여 tracker, sessionId를 초기화한다. 얼굴 누락, 품질 기준 이탈, 500ms 영상 정지, 숨겨진 탭 모두 같은 경로를 사용한다. `confirmScan()`도 tracker를 초기화한다. 현재 테스트는 이 초기화를 기대하므로 변경해야 한다.

## 접근 비교
1. 각도·모델 기준만 완화: 변경은 작지만 한 번의 누락이 전체 진행률을 지우는 원인은 남음.
2. 진행률과 현재 추적을 분리하고 복구 대기 도입 (권장): 이미 얻은 퍼센트·완료 부위·sessionId는 유지하되, 끊긴 구간의 손 움직임 연결을 제거. 일시적인 누락에서 자동 복구 가능.
3. 얼굴 식별 기반 재연결: 사용자 교체 판별에 도움이 될 수 있으나 얼굴 식별·추가 데이터 처리로 범위가 커짐.

## 제안 동작
- 최초 얼굴 스캔과 시작 확인은 유지.
- 관찰 중 얼굴 누락·자세 기준 이탈 시 진행률을 보존하고 유효한 동작 적립을 즉시 중지. 잘못된 좌표나 이전 프레임을 사용하지 않음.
- 2초 이내 정상 얼굴 복귀 시 같은 세션으로 자동 재개. 중단 전후 움직임·시간을 합쳐 완료시키지 않음.
- 2초 이상 이탈, 영상 정지, 탭 비활성화, 여러 얼굴 감지 시 재스캔과 시작 확인을 요구하되 기존 진행률·완료 부위는 보존.
- 관찰 중 작은 흔들림에서 안내가 즉시 재스캔으로 전환되는 현상을 복구 대기로 완화. 검증되지 않은 모델 신뢰도 하향은 하지 않음.
- 명시적 다시 시작, 카메라 종료·새 세션은 진행률을 초기화.
- 진행률은 동일 카메라 세션의 메모리에만 유지. 얼굴 동일인 식별은 제공하지 않으며, 사용자 교체 시 다시 시작 필요.

## 검증
일시 누락·자세 이탈 후 복귀, 장시간 이탈 후 재확인, 영상 정지·탭 비활성·여러 얼굴, 명시적 초기화, 부분 진행률·완료 부위·sessionId 보존, 누락 중 적립 및 잘못된 완료 방지를 단위 테스트로 고정. 브라우저 테스트로 화면 진행률과 복구 흐름 확인.
