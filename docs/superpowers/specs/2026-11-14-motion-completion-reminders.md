# 동작 진행률과 완료 후 재도포 알림

사용자 요청일: 2026-11-14. 동작이 인식되는 동안 퍼센트가 올라가고, 완료하면 직전 도포 시각과 UV별 재도포 알림에 연결한다. 기존의 수동 기록 전용 정책을 이 요청에 맞게 변경한다.

## 진행률의 의미

카메라로 선크림의 실제 양·두께·차단력을 측정하지 않는다. 화면 명칭은 **동작 진행률**이다. 이마·코·양 볼·턱의 정면 5구역을 대상으로 하며, 눈가·귀·목을 포함한 얼굴 전체 도포율로 표시하지 않는다.

구역별 유효 연속 손 움직임에서 다음 달성 비율의 최솟값을 퍼센트로 표시한다.

- 움직인 시간 / 2초
- 얼굴 좌표계 이동 거리 / 0.45
- 얼굴 좌표계 이동 범위 / 0.08

기존 머리 움직임 보정·최소 속도·손 대응·스캔 품질 조건을 그대로 적용한다. 시간만 지나거나 손을 가만히 대는 것으로 증가하지 않는다. 완료 조건 전에는 최대 99%, 기존 검출 조건을 모두 만족하면 100%다. 전체 진행률은 5구역 퍼센트의 동일 가중 평균을 내림한 값이다.

구역을 옮기거나 손이 잠시 사라지면 최고 진행률을 유지한다. 끊긴 관찰 시간을 더해 완료하지 않으며 새 연속 동작이 이전 최고치에 도달한 뒤 증가한다. 얼굴 추적 손실·다중 얼굴·탭 숨김·500ms 이상 처리 공백 또는 다시 시작은 기존 스캔 흐름에 따라 전체 진행률과 세션을 초기화한다.

## 완료와 기록

스캔 확인 후 관찰을 시작할 때 새 세션 ID를 발급한다. 5구역 모두 100%가 된 최초 프레임에 `completedAt`을 기록하고 `completed`로 전환한다. 분석 루프와 모델을 종료해 동일 완료 이벤트가 반복되지 않게 한다. 미리보기 카메라는 사용자가 끌 수 있으며, **새 도포 시작**으로 새 스캔·새 세션을 시작한다.

완료 이벤트는 공통 선케어 상태의 `recordMotionCompletion`으로 전달한다. `motion:<sessionId>` 기록과 `source: motion`을 저장하고, 화면의 직전 시각·타임라인에 **동작 완료 자동 기록**을 표시한다. 같은 분의 직접 입력은 완료 시각으로 갱신해 같은 도포가 두 건으로 보이지 않게 한다. 완료 세션 최근 200개를 저장해 중복 이벤트가 기록 취소나 알림 끄기를 되돌리지 못하게 한다. 기존 v1 수동 기록은 그대로 복원한다.

부분 동작·분석 중지·오류는 기록하지 않는다. 기록 취소와 직접 시각 입력은 계속 사용할 수 있다. 영상·특징점은 저장·전송하지 않으며 저장소에는 완료 시각·출처·중복 방지 ID만 추가한다.

## UV별 알림

완료 시각을 기준으로 해당 한국 날짜의 알림을 켜고 기존 종료 시각을 유지한다. 종료 시각이 지났으면 조정 안내를 보여 준다. 알림 확인 자체로 재도포를 기록하지 않는다.

| 현재 유효 UV | 주기 |
| --- | --- |
| 0–2 | 대기; 이후 높은 예보 구간에서 재개 |
| 3 | 150분 |
| 4–5 | 120분 |
| 6–7 | 80분 |
| 8 이상 | 60분 |
| 없음·오래된 데이터 | 120분 |

위치 갱신에 이미 동의한 경우에만 완료 직후 새 위치·기상청 예보를 요청하고, 응답에 따라 다음 알림을 재계산한다. 동의하지 않았거나 조회가 실패해도 완료 기록은 유지한다. 기기 알림 권한은 기존 버튼으로 요청하며 자동 완료에서 권한 창을 띄우지 않는다. 페이지를 열어 둔 상태의 화면 알림 동작 범위와 30분 예보 갱신은 기존과 같다.

## 검증

- 단위 테스트: 부분 진행률 증가·유지·초기화, 정지/머리 움직임 차단, 5구역 완료, 완료 시각/세션 1회 방출, 모델 해제, 부분 중지 시 미기록, 자동 기록 복원·취소·중복·같은 분 처리, 새 세션 알림 재계산, UV 높은 구간/낮은 구간 연결.
- Chrome 통합 테스트: SDK 출력만 합성 특징점으로 대체하고 실제 추적기·세션·화면·저장 로직으로 부분 진행 → 100% → 자동 시각 기록 → UV 7의 80분 일정 → 80분 후 화면 알림과 새 위치 조회 → UV 0 대기 → 새로고침 복원을 검사한다. 합성 데이터는 테스트 파일에만 둔다.
- 기존 실제 MediaPipe 초기화·카메라 자원 해제, 직접 기록·알림·위치·모바일 레이아웃 테스트를 유지한다.
- 실제 기기·사용자의 선크림 도포량 측정 정확도를 검증한 결과는 아니다. 인식 기준은 실제 기기에서 별도 보정이 필요하다.
