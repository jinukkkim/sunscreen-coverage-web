# 끊김 이후 동작 진행률 누적

사용자가 승인한 방식: 같은 세션의 같은 부위에서 확인된 유효 동작을 누적한다. 현재 연속 관찰의 최댓값만 보존해 짧은 관찰이 반복되면 진행률이 정체된다.

## Approaches

- 선택: 부위별 유효 동작 누적. 인식 공백 이후에도 실제 관찰한 동작만 이어 더한다.
- 대안: 연속 관찰의 2초 기준 단축. 끊김에 따른 정체를 해결하지 못한다.

## 설계

- 부위별 유효 시간(코 1000ms, 턱 1500ms, 이마·양 볼 각각 2000ms)과 경로 .45(눈 사이 거리 단위)를 누적한다. 각 연속 관찰에서 움직임 범위 .08 이상이 확인된 이후의 움직이는 프레임만 더한다.
- 손 분실, 얼굴 분실, 부위 전환, 긴 프레임 공백과 `interrupt()`는 현재 궤적만 끊고 부위별 누적은 보존한다. 공백을 가로지른 위치 차이는 누적하지 않는다.
- 정지, 작은 떨림, 머리만 움직임, 모호한 손 매칭은 누적하지 않는다. 같은 프레임의 같은 부위에 여러 손이 있어도 시간은 한 번만 더한다.
- 5부위 각각 완료해야 전체 100%다. `reset()`은 누적을 지운다. 사용량·실제 선크림 존재·보호 성능을 측정한다는 의미는 아니다.
- 실제 기기에서의 체감 속도는 카메라 추적 품질에 좌우되며 추가 확인이 필요하다.

## 부위별 시간 조정

사용자가 코 1초, 턱 1.5초, 이마·양 볼 각각 2초를 승인했다. 면적을 실측해 계산한 값이 아닌 동작 진행률을 위한 제품 설정이다. 최소 이동 거리와 범위, 5부위 완료 조건은 유지한다.
