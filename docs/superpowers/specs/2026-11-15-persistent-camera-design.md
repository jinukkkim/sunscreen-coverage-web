# 계속 유지되는 선케어 카메라

사용자 요청: 제품 등록도 얼굴 측정과 같은 카메라·화면을 사용하고, 사진 선택을 제거하며 카메라 영역을 끝까지 유지한다.

## 구현 결정
- 후속 요청: 제품 촬영 순간 미리보기를 pause하고 인식·결과 확인 중 촬영 화면을 유지한다. 다음 단계·건너뛰기·재촬영 때 같은 스트림을 play로 재개한다. 고정 화면을 별도 파일로 저장하지 않는다. 탭 숨김·끄기는 기존처럼 트랙을 해제한다.
- 후속 사용자 요청: 등록 결과를 표시한 뒤 명시적 다음 단계 버튼으로 이동한다. 건너뛰기는 저장 제품을 지우지 않고 이번 흐름만 미등록으로 진행하며, 제품별 길이 환산을 표시하지 않는다.
- 사용자 추가 요청: 데스크톱은 기존 크기의 왼쪽 카메라·오른쪽 정보 2열 배치로 유지하고 모바일은 세로 배치한다.
- CareFlow가 한 번 마운트한 Camera와 video ref를 모든 단계에서 공유한다. 한 번 시작한 전면 카메라 스트림은 제품 인식·얼굴 측정·용량 안내·동작 스캔 사이에서 유지한다.
- 제품 단계는 화면 중앙 가이드 안의 제품을 촬영하고 JPEG로 변환해 기존 동의·Gemini API로 인식한다. 읽힌 첫 후보가 등록 요건을 만족하면 저장 후 제품명·SPF·PA 등 결과를 표시한다. 사용자가 **다음 단계로**를 눌러 진행한다. 누락·실패 시 재촬영 또는 직접 입력을 제공한다.
- 제품 촬영 영역에 얼굴·배경이 포함될 수 있음을 동의 문구에 알린다. 얼굴 측정·스캔 단계의 이미지는 외부 전송하지 않는다.
- 얼굴 측정은 같은 video의 현재 프레임을 로컬 분석한다. 메인 흐름의 파일 입력을 모두 제거한다. 기존 `/face-dose.html`은 현재 홈의 같은 영역으로 연결한다.
- 단계가 바뀌면 이전 비동기 작업과 추론만 취소한다. 카메라 끄기·탭 숨김·페이지 종료·최종 완료 시에는 트랙을 해제하고 화면 영역과 video 요소는 남긴다.
- 완료·UV·알림 정책은 유지한다. 새로운 의존성은 추가하지 않는다.

## 대안
단계마다 같은 모양의 카메라를 다시 마운트하는 방법은 스트림·권한·미리보기가 끊기므로 사용자 요구를 충족하지 않는다. 고정 Camera 하나에서 단계별 버튼과 추론 작업을 전환한다.

## 검증
파일 입력 없음, 제품 인식 결과 확인 후 명시적 다음 단계·건너뛰기, 동일 video DOM/단일 getUserMedia 스트림 유지, 제품 촬영 영역 크롭, 전송 동의·취소, 얼굴 측정 로컬 처리, 추론 실패·취소·숨김과 완료 자원 해제, 기존 기록 중복 방지와 UV 정책을 테스트한다.

## 최신 main 통합

`main`의 SUNFIT 테마·공통 헤더/푸터·기상청 UV·가로 타임라인·누적 동작 추적과 삼각형 메시 채움을 유지한다. 도포 스캔 단계는 정면 얼굴 2초 안정 감지 후 자동 시작하며 수동 부위 확인 버튼을 두지 않는다. 완료 시 영상과 메시를 메모리 캔버스에 고정한 뒤 트랙을 해제한다. 큰 사용량 숫자와 검지 마디 길이 조절도 유지한다.
