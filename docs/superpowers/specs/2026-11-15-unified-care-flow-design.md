# 하나로 이어지는 선케어 흐름

상태: 승인됨 (2026-11-15 사용자 구현 요청). 카메라 수명·사진 선택·제품 자동 진행은 이후 [고정 카메라 설계](2026-11-15-persistent-camera-design.md)의 사용자 수정 요청으로 대체됨.

## 목적과 범위

내 선크림 등록 → 얼굴 크기 측정 → 도포 용량 안내 → 도포 동작 스캔 → 바른 시각 기록과 알림을 메인 React 화면의 순차 흐름으로 연결한다. 타임라인과 자외선 예보는 그 아래에 계속 표시한다. 기존 제품·기록 데이터를 보존한다.

## 접근 방식

별도 페이지를 이동하며 결과를 저장하는 방식은 화면과 상태 전달이 분리된다. 모든 기능을 한꺼번에 펼치는 방식은 현재처럼 사용 순서가 불명확하다. 기존 컴포넌트와 계산 함수를 재사용하는 메인 화면의 단계형 구성을 제안한다. 새 의존성은 추가하지 않는다.

## 화면과 동작

1. **내 선크림 등록:** 기존 제품 라벨 촬영·후보 확인·직접 입력을 사용한다. 저장된 제품이 있으면 요약과 수정 기능을 표시하고 그 제품으로 다음 단계에 진행한다. 외부 Gemini 전송 동의를 유지한다.
2. **얼굴 크기 측정:** 별도 가이드의 카메라 촬영과 얼굴·홍채 분석을 React 흐름에 통합한다. 사진 선택 대안과 품질 오류·재촬영을 제공한다. 촬영·분석 완료 후 카메라를 종료한다.
3. **도포 용량 안내:** 앞 단계의 모델 영역 면적과 계산량을 표시하고 스캔으로 진행한다. 평균 홍채 가정에 따른 추정이며 전체 얼굴의 실측 면적이 아님을 설명한다. 손가락 길이 환산은 미보정 참고값이다. 기존 가이드에 고정된 조선미녀 제품명을 등록 제품의 실측 토출 정보처럼 사용하지 않는다. 스틱·스프레이 등은 검증되지 않은 길이 환산을 적용하지 않는다.
4. **도포 스캔:** 기존 얼굴 정렬·다섯 부위 진행률·복구 동작을 재사용한다. 다섯 부위 모두 100%일 때만 완료 처리한다. 뒤로 이동하면 카메라와 진행 중 작업을 해제한다.
5. **완료:** 기존 완료 핸들러로 세션당 한 번 기록하고 한국 날짜 기준 오늘의 알림을 켠다. 설정된 종료 시각과 UV 주기 정책을 유지한다. 완료 시각·다음 알림·기기 알림 권한 버튼을 표시하고 다시 바르기 흐름을 제공한다.

상단에 현재 단계를 표시하고 이전 단계로 돌아갈 수 있게 한다. 재측정 시작 시 이전 측정 결과와 용량 안내를 무효화한다. 제품만 바꾸면 얼굴 측정 결과는 유지하되 제품별 안내는 갱신한다. 등록 제품은 기존 localStorage를 사용하고 얼굴 사진·랜드마크·측정 결과는 브라우저 메모리에서만 보관한다. 새로고침 후에는 저장된 제품 확인부터 시작한다.

아래에는 기록·알림 설정, 하루 타임라인, 위치·UV 예보를 둔다. 수동 시각 기록은 기존처럼 사용할 수 있으며 단계 완료로 간주하지 않는다. 위치와 기기 알림은 동의 없이 켜지 않는다. 카메라는 사용자가 시작하며 단계 전환·화면 숨김·종료 때 해제한다.

## 검증과 한계

단계 전환, 등록 제품 재사용, 재측정 무효화, 불완전 스캔 미기록, 완료 기록 중복 방지, 알림 종료 시각 보존을 검증한다. 기존 단위 테스트·빌드·Chrome E2E와 Astryx doctor를 실행한다. 실제 카메라 권한과 촬영 품질은 기기 확인이 필요하다.

실제 선크림 존재·도포량·차단력 인식은 이번 변경 범위에 포함하지 않는다. 용량 계산은 기존 모델의 추정값이며 제품별 토출량 보정을 새로 구현하지 않는다.
