# 카메라 자동 시작과 화면 정리

사용자 요청: 숫자를 크게 표시하고, 얼굴 인식이 일정 시간 유지되면 별도 버튼 없이 도포 동작 관찰을 시작한다. 상단 오렌지 소개 박스, 얼굴의 사진 분석 입력, 하단 소개 제목과 빈 안내 박스를 제거한다.

- 기존 Astryx 화면 구조와 테마를 유지한다. 사용량·면적·손가락 마디 수를 큰 숫자로 표시하고, 실시간 계산량과 마디 안내를 나누어 읽기 쉽게 한다. 전체 진행률은 큰 숫자, 부위별 진행률은 강조 숫자로 표시한다.
- 상태는 카메라 오른쪽 위의 기존 FACE GUIDE 자리에만 표시한다. 카메라 대기·연결·인식 준비·스캔·자동 시작 준비·복구·완료 상태를 반영하고, 추적 중에는 ‘제품을 바르세요’로 안내한다. 진행률 패널과 카메라 제목 옆의 중복 상태는 제거하고, 부위별 관찰 중 문구는 ‘바르는 중’으로 표시한다. 같은 상태는 반복 DOM 갱신 없이 유지해 라이브 영역이 매 프레임 반복 안내하지 않도록 한다.
- 카메라를 켜는 동작과 브라우저 권한 승인은 유지한다. `AUTO_START_MS = 2000` 동안 유효한 단일 정면 얼굴과 안정적인 위치가 지속될 때만 관찰로 전환한다. 1초 준비 상태에서 같은 VIDEO 얼굴 특징점으로 사용량을 먼저 계산한다. 계산 실패가 동작 관찰을 자동 완료하거나 기록하지는 않는다.
- 얼굴 없음·복수 얼굴·큰 움직임·자세 불량·500ms 초과 처리 공백·탭 숨김에서는 카운트를 다시 시작한다. 짧은 인식 복구는 기존 흐름을 따르며, 재스캔 시 기존 도포 진행률을 보존하고 2초 안정 후 자동으로 이어간다. 다른 사용자는 다시 시작으로 초기화해야 한다.
- 카메라 종료·연결 취소·초기화·언마운트에서 기존 스트림·추론 수명 관리를 유지한다. 자동 시작은 관찰만 시작하며, 5구역 완료 시점의 기록·UV별 알림 연결은 기존과 같다.
- 홈의 오렌지 Hero, 얼굴 사진 분석 탭·파일 입력·사진 처리 경로, ‘내 얼굴에서, 내 손끝으로.’ 제목과 빈 안내 박스를 제거한다. 실제 계산된 사용량·면적·손가락 결과는 계산 성공 후 표시한다. 제품 라벨 사진 인식은 별도 기능으로 유지한다.
- 단위 테스트는 정확한 2초 경계, 카운트 초기화와 중지 후 자동 시작 방지를 검사한다. Chrome 테스트는 확인 버튼 없이 한 스트림으로 사용량→동작 관찰→완료 기록, 실패 시 계산량 초기화, 숫자 크기와 모바일 넘침, 권한 취소·모델 지연·페이지 숨김을 검사한다.
