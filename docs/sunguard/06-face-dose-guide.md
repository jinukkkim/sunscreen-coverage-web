# 얼굴 면적·손가락 사용량 실험 가이드

기본 도포 동작 관찰과 분리한 선택형 페이지다. 카메라 또는 사용자가 선택한 사진에서 얼굴 메시를 추정하고, 검출된 일부 영역의 면적 계산과 표준 조건 손가락 길이 참고값을 보여준다. 사진은 브라우저 메모리에서 처리하며 기록·업로드하지 않는다.

## 추정 흐름

1. MediaPipe Face Landmarker가 한 사람의 얼굴과 양쪽 홍채가 있는 478개 랜드마크를 찾는다.
2. 평균 홍채 지름을 11.7mm로 가정해 픽셀 좌표를 크기로 환산한다. 얼굴 윤곽이 잘렸거나, 홍채가 너무 작거나, 양쪽 눈 깊이 차이가 큰 경우는 거절한다.
3. 얼굴 메시의 일부 삼각형 면적을 더하고, 눈과 입술 안쪽에 중심점이 들어가는 삼각형은 제외한다. 깊이는 모델의 relative-z 추정값을 사용한다.
4. 화면에 강조된 모델 영역의 계산 면적(cm²)에 시험 도포 기준 2mg/cm²를 곱해 계산량을 표시한다.
5. 질량을 표준 시연 조건인 지름 5mm 선크림 줄 25mm당 0.5g으로 길이로 환산한다. 기본 검지 첫 마디 길이는 25mm이며 15–40mm 범위에서 조절할 수 있다.

## 포함 범위와 제한

강조 영역은 랜드마크 메시가 차지하는 영역이다. 이마 위쪽 일부, 얼굴 옆면, 귀, 목 등은 충분히 포함되지 않을 수 있다. 상대 깊이는 실측된 얼굴 곡면이 아니다. 한 장의 사진에서 실제 피부 전체 표면적을 알아내거나 개인별 필요량을 확정하지 않는다.

홍채 기준 11.2–12.2mm 변화에 따른 결과는 기준 가정 하나의 민감도만 보여준다. 신뢰구간, 정확도, 전체 오차범위가 아니다. 옆으로 돌아간 정도는 좌우 눈 깊이 차이로 일부 거절하지만, 모든 위아래 기울기·표정·원근·가림을 판별하는 장치가 아니다.

2mg/cm²는 FDA의 SPF 시험에서 사용하는 면적당 적용량을 계산에 참고한 것이다. 본 앱은 SPF 시험이나 보호력 측정을 하지 않는다. 시험 농도를 표시된 부분 얼굴의 권장 도포량으로 일반화하지 않으며 제품 라벨을 우선한다. [FDA 시험 지침](https://www.fda.gov/media/85172/download).

제품 예시는 사용자가 지정한 조선미녀 맑은쌀 선크림 아쿠아프레쉬 10mL 비매품이다. 해당 용기 입구 직경·제형별 압출량·1회 질량을 측정하지 않았다. 손가락 줄 환산은 사용자가 짤 양을 실제로 계량하지 않는다. 5mm·25mm·0.5g 조건은 조절 가능한 개인별 실측값도, 제품 자료도 아니다.

## 기술 및 데이터

- 별도 페이지: `/face-dose.html` (HTML/CSS/JavaScript).
- 추정: `src/lib/measurement.js`, `src/lib/topology.js`, `src/lib/dose.js`.
- 캡처·표시: `src/face-dose/main.js`, `src/lib/ui.js`.
- Face Landmarker 모델은 공용 `scripts/prepare-vision.mjs` 절차로 `public/vision/`에 준비한다. 얼굴/손 공통 런타임과 모델 출처는 [제3자 고지](../../THIRD_PARTY_NOTICES.md)를 따른다.
- 실제 사용자가 선택한 사진은 저장소에 포함하지 않는다. 단위·스케일·도스 산식은 synthetic landmark 테스트로 확인하며, 테스트 통과는 실제 측정 정확도 검증이 아니다.
