# 도포 동작 베이스라인 검증

작성일: 2026-11-14. 대상은 실제 선크림 검출이 아니라 얼굴 정면 5구역의 펴 바르기 동작 관찰이다.

## 자동 검증

`npm test`는 카메라 수명, 얼굴 구역·좌표 정합성, 동작 누적, 모델 세션 취소·추적 손실, 자산 무결성을 검사한다. `npm run build`는 모델 자산 준비 후 Vite 번들을 생성한다. 테스트 통과를 실제 사용자 정확도로 해석하지 않는다.

- 실제 모델 다운로드 파일은 manifest의 SHA-256과 대조한다.
- 실제 패키지의 얼굴·손 모델 로딩은 Chrome의 가상 카메라로 확인한다. 가상 영상에는 실제 사람의 얼굴이 없다.
- UI의 긍정 동작 경로는 별도의 모의 특징점으로 확인한다. 모델이 실제 사람의 펴 바르기를 잘 추적한다는 증거가 아니다.
- 정지·통과·고개 이동·두 손·프레임 손실은 합성 특징점으로 검사한다.
- 실제 참가자 영상·사진·생체 특징점은 수집하거나 Git에 저장하지 않는다.

## 브라우저 검증 기록

| 확인 항목 | 입력 | 결과 |
| --- | --- | --- |
| 실제 얼굴·손 모델/WASM 로딩 | Chrome 가상 카메라 | 통과 |
| 외부 네트워크 요청 없음 | 앱 시작·모델 로딩·분석·종료 | 통과 |
| 카메라 권한 거부와 재시도 | 권한 실패 모의 입력 | 통과 |
| 스캔 확인 전 동작 미누적 | canonical 특징점 | 통과 |
| 올바른 사용자 좌우의 결과 표시 | 모의 오른쪽 볼 동작 | 통과 |
| 초기화·얼굴 손실·카메라 종료 | 모의 특징점/가상 카메라 | 통과 |
| 모바일 폭과 데스크톱 레이아웃 | Chrome viewport | 통과 |
| 실제 참가자의 동작 정확도 | 미수행 | 미확인 |
| 휴대폰 실기기·조명·피부/제품 다양성 | 미수행 | 미확인 |

SDK 1.2.3의 브라우저 실행에서 `https://odml.pa.googleapis.com/v1/log` 통계 요청을 발견했다. 자동 로깅 코드가 없는 0.10.32로 교체한 뒤 외부 요청 검사를 다시 실행해 통과했다. 원본 영상이 전송됐다는 관찰 결과는 아니다.


검증 환경: macOS, Node v24.14.1, npm 11.11.0, 설치된 Google Chrome의 headless 모드 및 Playwright 1.58.2. 실제 카메라 대신 가상 영상으로 실행했다. 실제 모델 로딩 실패 후 재시도도 통과했다. 자동 테스트 31개 및 Vite 프로덕션 빌드가 통과했다.

## 실기기 실험 절차 — 아직 수행하지 않음

동의한 참가자가 동일 기기·카메라 거리에서 아래 동작을 수행한다. 제품명이나 개인 정보는 필요하지 않으며, 기기·브라우저 버전·조명 조건·관찰 부위·시도 수·성공/오탐/추적 실패·감지 지연만 비식별 기록한다. 원본 수집이 필요해지면 수집 전에 동의·보관·삭제 방식을 별도로 정한다.

| 조건 | 확인할 동작 | 시도 수 | 감지/오탐 | 추적 실패 | 감지 지연 |
| --- | --- | --- | --- | --- | --- |
| 각 5구역 문지르기 | 의도한 구역에서 감지되는지 | | | | |
| 두 손 문지르기 | 각각 관찰하되 시간이 합산되지 않는지 | | | | |
| 정지한 손 | 감지되지 않는지 | | | | |
| 얼굴 앞 짧은 통과 | 감지되지 않는지 | | | | |
| 고개만 움직임 | 감지되지 않는지 | | | | |
| 공중 문지르기 | 실제 접촉과 구분 못 하는 오탐 기록 | | | | |
| 빈손/보습제 사용 | 선크림 존재를 판단 못 하는 한계 기록 | | | | |
| 이미 선크림이 발린 상태 | 동작 없이는 도포를 알아내지 못함 | | | | |
| 얼굴/손 가림·각도·조명 변경 | 보류·재스캔과 실패 기록 | | | | |

스캔 효과를 확인하려면 같은 합성/동의된 실험 시퀀스에 대해 고정 화면 구역 방식과 얼굴 특징점을 따라가는 방식을 비교한다. 부위 할당 오류, 동작 오탐/미탐, 추적 실패와 판단 보류를 각각 기록한다. 스캔의 효과와 실제 도포 검출 성능을 같은 수치로 합치지 않는다.

최종 제품 목표인 실제 누락 부위 검출은 제품별 도포 정답 데이터로 따로 평가해야 한다. 유기·무기·혼합·틴티드·투명 제형과 건조 전후, 미도포·보습제·물기 대조군을 포함하고 인물·제품·촬영 회차가 학습/평가에 섞이지 않게 한다.
