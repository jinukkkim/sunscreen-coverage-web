# 기본 카메라 선크림 도포 인식의 가능성과 한계

정리일: 2026-11-14. 문헌 조사와 기획 판단이며 직접 실험 결과가 아니다.

## 결론

일반 카메라에서 보이는 제품 흔적·색·광택은 관찰할 수 있다. 그러나 투명하게 마른 제품까지 포함해 실제 도포 유무·양·차단력을 신뢰성 있게 판정하는 기술이 SunSense 또는 SUNFIT에서 검증됐다는 근거는 확보하지 못했다. **가능성 미검증과 원리적 불가능을 구분한다.**

| 목표 | 판단 |
|---|---|
| 얼굴 부위와 손의 움직임 | 위치 추적 기반 행동 체크 가능. 실제 크림 접촉·깊이는 별도 |
| 흰 잔여물·뭉침 | 보이는 흔적 관찰 가능 |
| 전후 색·광택 변화 | 촬영 조건을 통제하면 비교 후보 |
| 투명 제품의 누락 영역 | 제품·피부·환경을 넘는 정확도 미검증 |
| 충분한 도포량·SPF·UVA 보호 | 일반 사진의 면적 점수에서 직접 도출할 수 없음 |

[색 변화 정량화 연구](https://pubmed.ncbi.nlm.nih.gov/29080360/)는 제품의 시각적 외관을 다룬다. 이를 도포량·보호 성능 검증으로 확대하지 않는다. [FDA 설명](https://www.fda.gov/drugs/understanding-over-counter-medicines/sunscreen-how-help-protect-your-skin-sun)은 SPF를 주로 UVB 보호 지표로 설명한다.

## RGB와 UV 촬영

일반 영상에서 생성한 히트맵은 AI 판단의 시각화이지 UV 측정값 자체가 아니다. 반사 UV 촬영은 UV를 통과시키는 광학계와 적절한 센서·광원을 이용하여 제품 유무의 대비를 관찰한다.

[JMIR 연구](https://derma.jmir.org/2021/1/e24653/)는 전용 UV 장비로 도포 누락을 평가했고, 일부 색조 제품의 식별 한계도 보고했다. 따라서 UV 사진도 모든 제품의 정답이나 SPF 측정기로 취급하면 안 된다. 사용한 장비·제품·방법의 적용 범위를 확인해야 한다.

기본 카메라의 모든 미세 UV 반응이 물리적으로 0이라고 주장하지 않는다. 이번 조사에서 일반 iPhone 카메라 단독으로 전 제형의 도포 상태를 정확하게 측정할 수 있다는 검증 근거는 찾지 못했다. 조명·필터·센서·감응 패치를 추가한 연구는 '기본 카메라만 사용'과 구분한다.

## 검증해야 할 혼동 요인

아래는 예상 실패 조건이다. 실제 제품에서 측정한 실패 목록이 아니다.

- 선크림 없는 보습제·오일·피지·물기 → 도포로 오인할 가능성.
- 매트하거나 투명하게 마른 선크림 → 미도포로 오인할 가능성.
- 얇은 막 → 존재는 찾더라도 양이 충분한지 판단하기 어려움.
- 조명·노출·화이트밸런스·각도·피부색·수염·화장 → 영상 차이의 원인이 섞임.
- 손이 얼굴 앞을 지나가는 동작 → 실제 접촉·제품 전달과 다름.

사진의 홍반 정량화에는 연구 근거가 있지만 환경·피부색·기기 영향을 검증해야 한다. [EQscore 연구](https://pubmed.ncbi.nlm.nih.gov/33113259/)를 선크림 검출이나 일광 손상 조기진단의 근거로 재사용하지 않는다.

## 다음 실험 제안

아직 수행하지 않은 제안이다. 구현 방식·표본 수·합격 기준은 미확정이다.

1. 대상부터 정의: 얼굴의 도포 유무/누락 영역을 볼 것인지, 양까지 측정할 것인지 구분한다.
2. 같은 촬영 조건에서 무도포·보습제만·선크림·부분 도포를 비교한다. 제형과 건조 전후를 나눈다.
3. 알려진 도포 영역·계량 기록 등 정답 근거를 만든다. UV 참고영상은 해당 제품에서 유효한 경우만 사용한다.
4. 피부색·인물·제품·기기·촬영 회차를 나눠 평가한다. 같은 인물의 비슷한 프레임이 학습·평가 양쪽에 섞이지 않게 한다.
5. 누락 부위를 놓친 비율, 바른 곳을 잘못 지적한 비율, 영역 겹침 정도와 판정 불가 비율을 확인한다. 정확도 숫자를 임의로 목표나 결과로 적지 않는다.
6. 결과가 나쁠 때 판단 보류가 가능한지, 동작 가이드만 쓸 때보다 실제 누락이 줄어드는지 확인한다.

## 반대 의견

- 가시적 단서만으로 다양한 제품의 도포 상태를 구분할 정보가 충분하지 않을 수 있다.
- 도포 유무 분류가 가능해도 충분한 보호 여부는 별도 문제다. 사용자에게 측정 범위를 정확히 전달해야 한다.
