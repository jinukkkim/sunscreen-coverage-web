# 제품 사진 데이터 흐름

- 정리일: 2026-11-15
- 적용 범위: "내 선크림 등록" 기능의 제품 라벨 사진. 제품·얼굴 단계는 하나의 카메라를 공유한다. 제품 단계의 명시적 촬영 영역만 전송하며 얼굴 측정·동작 스캔의 프레임은 로컬 처리한다.
- 근거 규정: `AGENTS.md` — 외부 분석 서비스를 도입하기 전에 이미지 전송을 문서화한다.

## 무엇이 전송되는가

| 항목 | 전송 여부 | 비고 |
|---|---|---|
| 제품 촬영 프레임의 중앙 가이드 영역 | 전송 | 화면에 보이는 4:3 영역 중 중앙 50% 너비·80% 높이를 잘라 긴 변 최대 1280px JPEG로 변환한다. 이 영역에 얼굴·배경이 포함되면 함께 전송될 수 있다 |
| 얼굴 측정·동작 스캔 프레임과 연속 영상 | 전송 안 함 | 고정된 `Camera.jsx` 스트림을 공유하지만 제품 단계의 촬영 버튼 외에는 이미지 전송을 실행하지 않는다 |
| 사용자 식별 정보 | 전송 안 함 | 로그인 없음. 쿠키·기기 ID를 붙이지 않는다 |
| 위치·UV 정보 | 전송 안 함 | 다른 기능의 데이터이며 이 요청에 포함하지 않는다 |

## 경로

```
브라우저 ──(동의 체크 후) POST /api/recognize {images:[{mimeType,data(base64)}]}──▶ server/app.js (Express)
server/recognize.js ──(메모리에서 그대로 전달)──▶ Google Gemini generateContent API
                ◀── JSON(브랜드·제품명·SPF·PA·제형·내수성·전성분·신뢰도) ──
브라우저 ◀── 검증된 JSON ── (등록 요건을 만족하면 저장·결과 표시 후 다음 단계 버튼, 누락 시 확인·수정 후 저장)
```

- 앱 서버(`npm run dev` / `npm start`)가 UV API와 같은 프로세스로 제공하며, 팀원 컴퓨터에서 Tailscale(`tailscale serve`)로 노출한다. HTTPS 종단은 Tailscale이 담당한다.
- 1차 모델이 혼잡하거나 35초를 넘기면 같은 사진을 `gemini-3.5-flash-lite`에 한 번 더 보낸다. 전송 대상은 동일한 Google Gemini API다.
- API 키는 서버 환경 변수(`GEMINI_API_KEY`)에만 있고 브라우저로 내려가지 않는다. 키는 요청 헤더(`x-goog-api-key`)로 보내며 URL에 넣지 않는다.

## 보관 정책

- 서버: 사진을 디스크에 쓰지 않고 로그에도 남기지 않는다. 요청 처리 후 메모리에서 해제된다.
- 브라우저: 인식 결과(텍스트)만 등록 완료 시 `localStorage`에 남는다. 사진·축소본은 저장하지 않는다.
- 외부 모델 제공자: Google의 API 데이터 처리 정책을 따른다. 무료 티어와 유료 티어의 데이터 사용 조건이 다를 수 있으므로 배포 전 팀이 사용 중인 티어의 약관을 확인하고 이 문서에 반영한다.

## 동의 흐름

- 분석 버튼 옆 체크박스는 기본 해제 상태이며, 체크하지 않으면 전송하지 않고 오류 문구로 안내한다.
- 문구는 전송 대상(외부 AI 모델, Google Gemini), 저장하지 않음, 제품 촬영 영역 안의 얼굴·배경도 함께 전송될 수 있으며 얼굴 측정·스캔 영상은 전송하지 않음을 명시한다.
- 동의 없이도 모든 값을 직접 입력할 수 있다.

## 제한과 주의

- 모델 출력은 "라벨에 인쇄된 것"의 전사이며 제품 성능을 검증한 값이 아니다. 화면에서도 그렇게 표기한다.
- 서버는 사진 2장, 장당 2MB, 요청 6MB를 넘으면 거절한다.
- 매장 매대나 타인의 제품을 찍을 때 배경에 사람이 들어가지 않도록 안내한다. 참가자 사진·영상은 저장소에 커밋하지 않는다.
- 모델 제공자를 바꾸거나 서버에서 결과를 저장하기 시작하면 이 문서를 먼저 갱신한다.
