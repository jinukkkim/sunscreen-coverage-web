# SunSense 상세 분석

대상: https://www.sunsense.app/ · 조사일: 2026-11-14.

## 확인 사실

아이폰 일반 카메라의 유분막 분석으로 미도포 영역을 표시하고, 피부 붉음·UV·알림·기록·로컬 AI를 제공한다고 설명한다. 별도 UV 장비 없이 사용한다는 주장이다. 정확도·데이터·평가 방법은 공개 자료에서 찾지 못했다.

공개 HTML을 직접 읽은 결과:

- App Store 버튼은 실제 링크 없이 준비 중 알림을 실행한다.
- 출시 예정 문구가 있고 대기 신청 입력 폼은 없다.
- 정책·약관·문의·지원은 모두 `href="#"`이다.
- 화면 속 29%·누락 4곳 결과는 삽입 이미지다. 동일 이미지가 두 곳에서 재사용된다.
- 붉음 점수 58은 HTML에 고정되어 있다.
- JavaScript는 스크롤·등장 효과이며, 공개 페이지에 촬영·추론 실행부는 없다.

원문: [SunSense](https://www.sunsense.app/). 이는 **공개 웹 페이지** 분석이다. 비공개 iOS 프로토타입의 존재나 부재를 입증하지 않는다. 결과 이미지가 조작됐거나 AI로 생성됐다고 판단하지 않는다.

## 제품·경쟁 해석

결과를 보여주고 재도포로 연결하는 사용자 흐름이 명확하다. 그러나 히트맵만으로 정확도를 판단할 수 없다. 표시 비율의 분모, 피부 영역 분할 기준, 임계값, 제품별 오판이 설명돼야 비교가 가능하다.

가장 큰 기술 질문은 반짝임을 찾는 것과 선크림을 식별하는 것의 차이다. 보습제·피지·땀을 선크림으로 오인하는지, 매트·투명 제형을 놓치는지 검증이 필요하다. 이는 예상 실패 조건이며 실제 제품에서 관찰된 오류가 아니다.

피부 붉음의 측정, 원인이 햇빛인지 판단, 보이지 않는 손상의 예측은 각각 다른 문제다. [홍반 정량화 연구](https://pubmed.ncbi.nlm.nih.gov/33113259/)는 영상 분석 가능성을 뒷받침하지만 SunSense의 정확도를 입증하지 않는다.

## 상태 판단과 SUNFIT에 주는 의미

공개 근거상 초기 소개·출시 준비 단계로 분류한다. 운영사·투자·매출·실사용 규모·독립 성능 평가와 과금 구조는 확인하지 못했다. 동명의 [노르웨이 센서 제품](https://sunsense.com/)의 이력·평점을 이 서비스에 연결하면 안 된다.

SUNFIT는 동작 기반 가이드가 구현된 상태다. 사용자가 새로 선택한 실제 도포 인식 목표는 별도 검증 과제다. SunSense의 존재만으로 일반 카메라 인식이 해결됐다고 판단하지 않으며, 출시 미확인만으로 경쟁 가능성을 배제하지 않는다.

## 반대 의견

- 정적 소개 사이트 뒤에 비공개 네이티브 앱이 있을 수 있으므로 웹 코드만으로 제품 전체의 기술력을 평가할 수 없다.
- 반대로 결과 이미지와 마케팅 설명만으로 신뢰할 수 있는 검출이 완성됐다고 볼 수도 없다.
