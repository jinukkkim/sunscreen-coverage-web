# SunGuard 프로젝트 방향

- 정리일: 2026-11-14
- 프로젝트 성격: 2026 서울시립대학교 해커톤 팀 공동 프로젝트.
- 사용자 결정: **선크림 도포 인식을 메인으로 하는 웹사이트를 프로젝트로 진행한다.**
- 기존 프로토타입: https://1.tail381297.ts.net/
- 문서 범위: 이번 대화의 선크림 관련 조사와 기술 판단. 실제 성능 검증·사용자 실험은 아직 없다.
- 목적 맥락: 서울시립대 AI+X 대회 아이디어 탐색에서 이어진 프로젝트. 상세 일정·팀명·팀원 명단·예산·사업 모델은 미확정.

## 목표와 현재 상태

주된 제품 과제는 사용자가 선크림을 바를 때 빠뜨린 부위를 알아차리고 보완하도록 돕는 것이다. 사용자가 확정한 중심은 도포 인식이며, UV 지수·알림·성분 분석은 기존 프로토타입의 보조 기능이다. 아래 기술 선택은 아직 확정되지 않았다.

| 구분 | 현재 의미 |
|---|---|
| 사용자 확정 | 선크림 도포 인식 중심, 웹사이트 형태 |
| 기존 시연에서 확인 | 얼굴·손 위치 기반 구역별 동작 체크 |
| 미검증 | 일반 RGB 영상에서 실제 선크림 도포 유무·면적을 판별하는 정확도 |
| 미확정 | 전용 UV 카메라 사용, 지원 제품·피부색·기기 범위, 배포 방식 |
| 입증하지 못한 것 | 충분한 도포량, SPF·UVA 차단력, 남은 보호 시간 |

**손이 지나간 기록과 실제 제품이 발린 상태는 다른 데이터다.** 사용자 목표를 동작 체크만으로 축소하지 않되, 현재 시연을 실제 도포 검출이 완성된 것처럼 설명하지 않는다.

## 기존 웹 프로토타입에서 확인한 기능

공개 HTML과 JavaScript의 화면 문구·기능 흐름을 읽었다. 카메라를 켜 실제 인식을 시험한 결과는 아니다.

- 위치별 UV 지수: Open-Meteo 시간대 예보, 서울 기본 위치, 현재 위치 선택, 시연용 UV 슬라이더.
- 얼굴 7구역: 이마·왼쪽 볼·오른쪽 볼·콧등·눈가·턱선·귀 주변.
- 얼굴·손 인식: 손끝을 구역 위에서 약 3초 움직여 체크. 카메라 없는 터치·마우스 시연도 제공.
- 진행률·구역 수·초기화, 도포 완료 후 덧바름 타이머.
- 제품 전성분표 사진 분석: JPG·PNG·WebP, 6MB 한도. Gemini 전송 안내와 샘플 제공.
- 아보벤존·옥시벤존 검출 시 시연에서 눈가 구역을 제외하는 규칙.
- 피부 유형별 선택 힌트. 제휴 카드는 실제 구매 링크 없는 시연.

얼굴 영상은 로컬 처리, 제품 사진은 분석 시 Gemini 전송이라고 안내한다. 전체 데이터 흐름을 독립적으로 감사한 것은 아니다. 성분 두 가지 검출만으로 개인의 자극 여부를 판정하거나 눈가 보호를 일률적으로 제외하는 규칙의 타당성은 검증하지 않았다.

## 가정과 다음 검증 과제

| 가정 | 상태 | 필요한 증거 |
|---|---|---|
| 기본 카메라에서 도포 전후 차이가 관찰된다 | 조건부 가능성 | 제품·조명·피부색별 촬영 비교 |
| 차이를 선크림과 다른 유분으로 구분할 수 있다 | 미검증·핵심 위험 | 보습제·피지·땀 등 음성 대조 |
| 투명하게 마른 뒤 누락 부위를 구분할 수 있다 | 미검증·핵심 위험 | 시간 경과·제형별 정답 데이터 |
| 얼굴·손 체크가 실제 누락을 줄인다 | 미검증 | 안내 전후 독립 도포 평가 |
| 카메라 사용이 습관으로 이어진다 | 미검증 | 반복 사용·중단 이유 관찰 |

검증 제안은 [기술 문서](03-recognition-feasibility.md)에 정리했다. 아직 실행 승인된 구현 설계나 확정 일정이 아니다.

## 결정 이력

1. 링크에 접근하지 못한 초기 조사에서 작업 폴더의 콘서트 아이디어를 잘못 연결했다. 사용자가 선크림 아이디어임을 바로잡았다. 잘못 진행한 콘서트 조사는 이 프로젝트의 경쟁 근거에 포함하지 않는다.
2. 로컬 네트워크에서 실제 페이지와 배포 JavaScript를 읽어 SunGuard임을 확인했다.
3. 유사 서비스, SunSense, 기본 카메라의 측정 한계를 조사했다.
4. 사용자가 도포 인식 중심 웹 프로젝트로 방향을 선택했다.
5. 보관 범위를 명확히 하여 선크림 문서는 GitHub 게시 대상인 `docs/`에, 선크림 이전 자료는 Git 제외 대상인 `archive/`에 둔다.

6. 팀 공동 저장소로 운영한다. 공개·MIT를 유지하며 저작권은 `SunGuard contributors`로 표기한다. Claude 코드 리뷰 연결은 하지 않는다.

## 반대 의견

- 보이는 색·유분의 변화가 충분한 자외선 차단을 뜻하지 않아 잘못된 확신을 줄 수 있다.
- 매번 촬영하는 수고가 사용자가 느끼는 이익보다 클 수 있다. 아직 사용자 검증은 없다.
